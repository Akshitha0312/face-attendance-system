# Face Recognition Attendance System

## Description
This project is a web-based attendance system that uses face recognition to automatically mark attendance using a webcam.

## Technologies Used
- Python
- OpenCV
- Flask
- HTML, CSS, JavaScript
- Chart.js
- NumPy, Pandas

## Features
- Face detection using Haar Cascade
- Face recognition using LBPH
- Automatic attendance marking
- Duplicate prevention
- Dashboard with graph and percentage

## How It Works
1. Capture face using webcam
2. Detect face using Haar Cascade
3. Recognize face using LBPH
4. Store attendance in CSV
5. Display data in dashboard

## How to Run
Run:
python app.py

Open:
http://localhost:5000

## Note
Dataset is not included due to privacy reasons.
